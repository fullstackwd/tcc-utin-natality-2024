Esta pasta contém arquivos de documentação e apresentação complementar do Trabalho de Conclusão de Curso.

## Arquivo principal

```text
index_tcc.html
```

O arquivo `index_tcc.html` é uma página HTML complementar de apresentação/documentação do TCC.

Para visualizar corretamente seu conteúdo, recomenda-se baixar o repositório ou o arquivo HTML para o computador e abri-lo localmente em um navegador.

## Como visualizar

### Opção 1 — baixar o repositório completo

No terminal, execute:

```bash
git clone https://github.com/fullstackwd/tcc-utin-natality-2024.git
cd tcc-utin-natality-2024
```

Depois, abra o arquivo:

```text
docs/index_tcc.html
```

Você pode abrir o arquivo dando dois cliques nele ou clicando com o botão direito e escolhendo:

```text
Abrir com → Google Chrome, Microsoft Edge, Firefox ou outro navegador
```

### Opção 2 — abrir com servidor local

Depois de baixar o repositório, entre na pasta principal do projeto e execute:

```bash
python -m http.server 8000
```

Em seguida, acesse no navegador:

```text
http://localhost:8000/docs/index_tcc.html
```

Essa opção é recomendada caso o navegador bloqueie algum recurso local ou caso a página utilize arquivos auxiliares do próprio repositório.

## Observação importante

O arquivo `index_tcc.html` é um artefato complementar de documentação e apresentação do projeto.

Ele não substitui a versão oficial do TCC entregue conforme as normas acadêmicas da UNIVESP. Sua finalidade é apoiar a comunicação técnica, a rastreabilidade e a transparência do pipeline desenvolvido.
